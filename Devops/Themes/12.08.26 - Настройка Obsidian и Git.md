## Что делали

- Подвязали локальное хранилище заметок Obsidian к удаленному репозиторию GitHub в ветку `playground`.
    
- Вышли из состояния `detached HEAD` и настроили правильное отслеживание ветки.
    
- Исключили системные файлы настроек Obsidian (`.obsidian/`) из индексации Git.
## Изученные команды и решения ошибок

### 1. Исправление detached HEAD

Bash

```
git checkout -b playground origin/playground # Создание локальной ветки playground и связывание её с отслеживанием origin/playground
```

### 2. Настройка .gitignore и очистка индекса

Bash

```
touch .gitignore # Создание файла исключений в корне репозитория для скрытия служебных файлов
git rm -r --cached .obsidian # Удаление папки .obsidian из индекса Git без удаления файлов с диска
```

### 3. Ежедневный цикл отправки заметок

Bash

```
git add . # Добавление всех новых и измененных файлов заметок в индекс
git commit -m "Add notes" # Фиксация сохраненных изменений в локальной истории Git
git push origin playground # Отправка всех новых коммитов в ветку playground на GitHub
```
